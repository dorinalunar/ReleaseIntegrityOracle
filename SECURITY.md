# Security Policy
## Supported Versions
Currently, only the latest version of the `ReleaseIntegrityOracle` smart contract is actively supported with security updates.

| Version | Supported |
| :--- | :--- |
| 1.0.x | :white_check_mark: |
| < 1.0.0 | :x: |

## Reporting a Vulnerability
We take the security of GenLayer smart contracts and GenVM consensus very seriously. 
If you discover a security vulnerability, please do **not** open a public issue. Instead, report it privately via GitHub's "Private vulnerability reporting" feature or contact the repository owner directly.
Please include:
* A description of the vulnerability.
* Steps to reproduce the issue.
* Potential impact on the GenVM consensus or state data.
You should receive a response within 48 hours. Thank you for helping keep the Web3 ecosystem secure!
